Bloco 04 · Tráfego Pago

Pixel
e Estrutura de Conta

O pixel é o sistema nervoso da sua operação: sem ele, a plataforma não sabe quem comprou, quem quase comprou e para quem otimizar. Vamos instalar, testar e organizar tudo.

Tempo: ~55 min Nível: Intermediário Exercício: Sim

Ao final deste módulo você será capaz de

  • Entender o que é o pixel e por que ele decide resultados.
  • Instalar e validar rastreamento em site ou página.
  • Estruturar BM, conta de anúncio e pixel de forma profissional.
  • Criar públicos personalizados a partir de eventos.

1. Pixel: o olho da máquina

O pixel (Meta Pixel / Tag do Google) é um código no seu site que reporta eventos: visita, clique no WhatsApp, envio de formulário, compra. Com esses dados, a plataforma:

  • Otimiza — entrega anúncios a quem se parece com quem converte;
  • Aprende — cada conversão ensina o algoritmo;
  • Mede — mostra qual campanha gerou resultado real;
  • Remarketa — permite anunciar só para quem visitou (módulo 28).

Sem pixel, você roda campanha vendada: paga, mas não ensina nem mede direito.

2. Instalação na prática

  1. No Gerenciador de Eventos → conectar dados → criar pixel;
  2. Site próprio: colar o código base no <head> de todas as páginas (ou via Google Tag Manager);
  3. Landing page em ferramenta: colar apenas o ID do pixel no campo integrado;
  4. Objetivo WhatsApp: criar evento personalizado de "clique no botão do WhatsApp";
  5. Testar: extensão Meta Pixel Helper (Chrome) deve acender verde com os eventos certos.

Evento-chave para negócio local

Se a conversão acontece no WhatsApp, marque o CLIQUE no link do WhatsApp como evento principal. É esse evento que a campanha de vendas vai otimizar — e cada lead passa a ser contabilizado.

3. Estrutura profissional de ativos

Nunca rode campanha do cliente na SUA conta pessoal: verba do cliente em ativo do cliente. Acesso concedido como parceiro, revogável a qualquer momento.

4. Públicos que nascem dos eventos

  • Visitantes 30 dias — base de remarketing;
  • Quem clicou no WhatsApp mas não comprou — público de recuperação;
  • Compradores — exclusão (não pagar pra quem já comprou) e semente de semelhantes;
  • Público semelhante 1–3% — a plataforma encontra parecidos com seus melhores clientes;
  • Envolvidos com Instagram/Facebook 90 dias — quentes para ofertas.

    • Exemplo prático · Estrutura mínima viável

    Campanha de vendas otimizando evento "clique WhatsApp" + público semelhante 1% + remarketing de visitantes 30 dias. Duas campanhas, pixel instalado, exclusão de compradores. É assim que operação pequena parece grande.

Exercício prático

Fundação técnica completa

  1. Instale um pixel em qualquer página sua (site, landing em construtor) e valide com o Pixel Helper.
  2. Crie o evento de clique no WhatsApp e dispare-o manualmente para confirmar registro.
  3. Monte a estrutura: BM → conta de anúncios → pixel → página vinculada.
  4. Crie 3 públicos personalizados: visitantes 30d, engajados IG 90d e compradores (simulado).
